# Release 0.19.5 — acesso ao consolidado geral

## Correção de navegação

A visão de todas as Work Packages coletadas por todos os usuários está disponível em **Gerência > Monitoramento de Work Packages > Consolidado de Work Packages**. Para torná-la facilmente localizável, a tela **Minhas Work Packages** passa a exibir o botão **Consolidado geral** quando o perfil ativo possuir o direito **Acessar a visão gerencial**.

## Validação

1. Em um perfil com **Acessar a visão gerencial**, abra **Gerência > Monitoramento de Work Packages**.
2. Confirme a presença do botão **Consolidado geral** ao lado de **Consultar minhas WPs**.
3. Abra o consolidado e confirme a exibição de WPs consultadas por diferentes usuários.
4. Em um perfil sem o direito, confirme que o botão não é exibido e que o acesso direto é bloqueado.
